# ألعاب الجلسة — تطبيق أندرويد

## الإعداد (مرة واحدة)
1. أنشئ مستودعاً جديداً على GitHub وارفع كل هذه الملفات (فرع `main`).
2. من **Settings → Pages** اختر Source: **GitHub Actions**.
3. من **Actions → Deploy Pages** شغّل الـworkflow يدوياً مرة (Run workflow).
4. من **Actions → Build APK → Run workflow** (اكتب الاسم) ثم حمّل الـAPK من **Releases**.

## التحديث عن بعد (بدون إعادة بناء)
- عدّل `docs/app.html` (الواجهة/اللعبة) ثم **غيّر `version`** في `docs/config.json` (مثلاً "2") وارفع (commit).
- يُنشر تلقائياً، وعند فتح التطبيق يجلب النسخة الجديدة.
- `title` في config.json يغيّر عنوان الصفحة، و`maintenance` برسالة يوقف التطبيق مؤقتاً.

## تغيير اسم التطبيق على الهاتف
الاسم تحت الأيقونة مكتوب داخل APK، لذلك يتغيّر بتشغيل **Build APK** باسم جديد
ثم تثبيت الـAPK الجديد فوق القديم (نفس `app_id`).
